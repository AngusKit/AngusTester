# Contributing

This repository hosts documentation and getting-started material for AngusTester, not application source code. As a result:

- **We do not accept source code pull requests here.** There is no buildable source in this repository to modify.
- **Documentation fixes are welcome.** If you spot an error, an outdated command, or a broken link in the README files, please open an Issue (or a PR against the README/assets) describing the problem.
- **Suite-level questions** (installing AngusTester together with other AngusKit products, licensing, upgrades) belong in [AngusKit/AngusKit](https://github.com/AngusKit/AngusKit).
- **Installation issues** for the Community Edition are welcome as Issues here; please include your OS, deployment method (Docker Compose / host ZIP / Kubernetes), and the relevant log output.
- For anything related to Team/Enterprise licensing, SaaS, or commercial support, use [anguskit.com/contact](https://www.anguskit.com/en/contact) rather than an Issue.

# 贡献指南

本仓库只承载 AngusTester 的文档与快速上手材料，不包含可运行的应用源码，因此：

- **本仓库不接受源码 Pull Request**——这里没有可修改、可构建的源码。
- **欢迎提交文档修正**。如果你发现 README 里的错误、过期命令或失效链接，欢迎提 Issue，或者直接对 README/assets 提 PR 说明问题。
- **套件层面的问题**（AngusTester 与其它 AngusKit 产品一起安装、许可证、升级）请提到 [AngusKit/AngusKit](https://github.com/AngusKit/AngusKit)。
- **社区版安装问题**欢迎在本仓库提 Issue，请附上操作系统、部署方式（Docker Compose / 主机 ZIP / Kubernetes）与相关日志。
- 涉及团队版/企业版许可、SaaS 或商业支持的问题，请走 [anguskit.com/contact](https://www.anguskit.com/zh/contact)，不要提 Issue。
